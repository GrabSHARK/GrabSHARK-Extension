[/settings/admin/email]
└─ File: grabshark/apps/web/pages/settings/admin/email.tsx
└─ Category: Config (admin-only)
└─ Purpose: SMTP server config UI for admins. Lives under "Admin Only" separator in SettingsSidebar (visible only when user.isAdmin). Structured form (raw URL alanı kaldırıldı): "Hızlı kurulum" provider preset chip'leri (Gmail / Outlook / Yandex — apps/web/lib/smtpPresets.ts statik tablosu, downloadCenterConfig kalıbı) host/port/şifrelemeyi prefill eder; aktif chip host değerinden DERIVE edilir (provider id saklanmaz). Chip seçiliyken app-password rehberi + From-eşleşme notu + resmi rehber dış linki içeren info kutusu render edilir; username blur'unda boş From alanı username ile seed'lenir. Alanlar: Host + Port + Şifreleme dropdown'ı (STARTTLS 587 / SSL-TLS 465 / None 25) + Username + write-only Password. Boş port seçili modun varsayılanı sayılır (placeholder = efektif değer). Dropdown değişince port otomatik dolar (custom port ezilmez); SSL/TLS↔port uyumsuzluğunda inline "wrong version number" uyarısı. Form GET response'un `server` view'i ile prefill olur; password boş bırakılırsa mevcut şifre korunur. URL compose sunucu tarafında (updateEmailConfig). Single-source DB-driven config: SystemConfig (id=1) singleton, AES-256-GCM encrypted URL (TOTP_ENCRYPTION_KEY). Admin saves/clears the row and can send a 5-second-timeout test email to their own address. invalidateTransporterCache() runs on save so live mail pickups happen without a restart.
