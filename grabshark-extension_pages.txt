== 4. Content Scripts: Page Interception & UI ==

[contentScript.tsx]
└─ File: grabshark-extension/src/pages/ContentScript/contentScript.tsx
└─ Category: Content Entry
└─ Purpose: Ziyaret edilen web sayfalarına sızan ana içerik betiği (Content Script). Observer ve UI yöneticilerini ayaklandırır.

[EmbeddedApp.tsx]
└─ File: grabshark-extension/src/pages/ContentScript/EmbeddedApp.tsx
└─ Category: Injected Root
└─ Purpose: Shadow DOM vasıtasıyla dış sitenin CSS ve düzeninden (layout) etkilenmeden çalışan, eklentiye ait gömülü arayüzlerin (Toast vb.) sarmalayıcısı.

[embeddedUI.ts]
└─ File: grabshark-extension/src/pages/ContentScript/embeddedUI.ts
└─ Category: Shadow DOM
└─ Purpose: Web sayfasının Document Body'sine izolasyon çerçevesi (Shadow Root) yerleştiren ve React'i buraya bağlayan motor.

== 5. Content Scripts: Highlight System ==

└─ File: grabshark-extension/src/pages/ContentScript/managers/HighlightManager.ts
└─ Category: Highlight Logic
└─ Purpose: Sayfada yapılan metin seçimlerini dinleyen, Background'a kaydeden ve çizim (renderer) motoruna komut veren menajer.

└─ File: grabshark-extension/src/pages/ContentScript/HighlightToolbox.ts

[SaveNotificationToast]

└─ Purpose: İçerik kaydedildikten veya bir eylem alındıktan sonra sayfanın sağ alt köşesinden estetik olarak beliren bildirim arayüzü.
