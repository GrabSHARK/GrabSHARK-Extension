GrabSHARK Main Application Tech Stack (Internal Engine & Libraries)

== Core Frameworks & Runtime ==

[Next.js]
└─ Category: Framework
└─ Purpose: Ana React frameworkü. Server Side Rendering (SSR), Static Generation (SSG) ve API rotaları sağlayan iskelet yapı.

[React]
└─ Category: UI Library
└─ Purpose: Kullanıcı arayüzünü inşa ettiğimiz temel JavaScript kütüphanesi.

[Node.js]
└─ Category: Environment
└─ Purpose: Backend ve server-side işlemlerin üzerinde koştuğu çalışma zamanı ortamı.

[TypeScript]
└─ Category: Language
└─ Purpose: Proje genelinde statik tip güvenliği (type-safety) sağlayan dil.

== Database, Auth & Security ==

[PostgreSQL]
└─ Category: Database
└─ Purpose: Sistemin ana ilişkisel veri tabanı motoru.

[Prisma]
└─ Category: ORM
└─ Purpose: PostgreSQL ile sunucu arasındaki veritabanı sorgularının yazılmasını sağlayan soyutlama katmanı.

[NextAuth.js]
└─ Category: Authentication
└─ Purpose: Oturum yönetimi, token kontrolü ve kimlik doğrulama çerçevesi.

[Bcrypt]
└─ Category: Cryptography

[DOMPurify]
└─ Category: Security
└─ Purpose: HTML formatındaki okuma modunda XSS gibi güvenlik açıklarını engelleyen entegre sanitasyon aracı.

== State Management & Data Fetching ==

[React Query / @tanstack/react-query]

[Zustand]

[Axios / Node-fetch]

└─ Purpose: Dış veya iç API'lerle haberleşmeyi sağlayan ağ istemcileri.

== Infrastructure, Workspaces & Testing ==

[Turborepo / Yarn Workspaces]
└─ Category: Monorepo Management
└─ Purpose: Kodu tek depoda (packages, apps) yönetebilmek, build sürelerini önbellek (cache) ile ciddi oranda düşürmek.

[Docker]
└─ Category: Containerization
└─ Purpose: Veritabanı, arka plan botları ve uygulamanın kendisinin her sunucuda "aynı" çalışabilmesi için kapalı izolasyon ortamı.

[Playwright]
└─ Category: Browser Automation & E2E Testing
└─ Purpose: Web sayfalarını arşivlemek için headless browser (screenshot, PDF, monolith HTML), ayrıca E2E test altyapısı. Worker'da primary browser olarak kullanılır. BrowserManager per-user `user.browserType='playwright'` + opsiyonel `useStealth` toggle ile seçilir.

[@playwright/test — E2E suite]
└─ Category: End-to-End Testing
└─ Purpose: `apps/web/e2e/` altındaki uçtan uca test altyapısı (2026-08-09). Gerçek uygulamayı gerçek Postgres'e karşı sürer — mock sunucu yok. Dört proje: `setup` (hesapları seed eder + storageState üretir) → `public` (oturumsuz yüzeyler) · `authenticated` (üye oturumu) · `admin` (ADMIN oturumu) · `mobile` (Pixel 5 viewport). Spec'in dizini hangi oturumla koşacağını belirler. İzolasyon: kendi sunucusu (port 3100, `E2E_PORT`), kendi veritabanı (`DATABASE_URL` + `_e2e` — kimlik bilgileri tek yerde kalsın diye türetilir), kendi Redis db'si (15). `globalSetup` her koşuda tabloları TRUNCATE eder → deterministik taban. Fixture'lar: `api` (ürünün kendi REST'i üzerinden seed), `freshUser` (tek kullanımlık hesap), `userCollection` (teste özel koleksiyon), `anonymousContext` (storageState mirasını kırar — Lesson 56). Selector kuralı `data-testid`. Dış servisler kapalı: SMTP yok, Telegram token'ı boşaltılır, Meilisearch devre dışı (index'i worker doldurur, o koşmuyor), Stripe key'i yok. Detay: `apps/web/e2e/README.md`.

[Playwright — CI E2E aşaması]
└─ Category: CI/CD Test Gate
└─ Purpose: Jenkins `E2E` stage'i suite'in tamamını **publish edilecek image'a karşı** koşar (per-build postgres + redis + app container, hepsi tek network'te). 2026-08-09'a kadar yalnız tek proje koşuyordu — auth arkasındaki her şey kapsam dışıydı; artık `playwright test` argümansız çalışıyor. `--grep` ile daraltmak YASAK: setup projesini de eler, kimse seed edilmez, ilk gerçek login 401 verir. Kırmızı E2E → image push edilmez. Artifact: `test-results/**` (screenshot, video, trace), `playwright-report/**`, `junit.xml`.

[playwright-extra + puppeteer-extra-plugin-stealth]
└─ Category: Stealth Plugin Layer
└─ Purpose: Playwright'in üstüne geçirilen stealth wrapper. `navigator.webdriver`, `chrome.runtime`, WebGL vendor gibi otomasyon izlerini gizler. `user.useStealth=true` ile etkinleştirilir. browser.ts'te `stealthChromium` olarak import edilir, plain `rawChromium` ile paralel kullanılır.

[CloakBrowser]
└─ Category: Stealth Browser (Opsiyonel)
└─ Purpose: 33 C++ source-level patch ile bot tespitine dayanıklı Chromium. Kullanıcı `user.browserType='cloakbrowser'` ile seçer. Per-user opsiyonlar: cloakStealth, cloakHumanize, cloakHumanPreset, cloakProxy, cloakTimezone, cloakLocale, cloakGeoip (hepsi DB'de User model'de). Library-level: CLOAKBROWSER_AUTO_UPDATE ve CLOAKBROWSER_CACHE_DIR env var'larıyla kontrol edilir.

[BrowserManager]
└─ Category: Worker Browser Lifecycle
└─ Purpose: `apps/worker/lib/browser.ts` modülü — 2-slot cache (Playwright + CloakBrowser) lazy mode için, per-link mode'da config-compare-reuse ile tek browser. Lifecycle env var BROWSER_LIFECYCLE=lazy|per-link ile kontrol edilir (default lazy). Config değişikliğinde slot kill & relaunch. Launch hatası → user.browserConfigError yaz + per-type defaults'a fallback. Eski 30-dakika rotation silindi.

[FlareSolverr (PR-1300)]
└─ Category: Anti-Bot Cookie Extraction
└─ Purpose: Cloudflare JS Challenge (eski tarz, iframe'siz) icin cookie extraction servisi. Sadece CLOUDFLARE_JS ResolutionStrategy'sinde kullanilir. Docker servisi: alexfozor/flaresolverr:pr-1300-experimental (port 8191).

[Challenge Detector (Refactored)]
└─ Category: Anti-Bot Detection
└─ Purpose: Live page state bazli challenge tespit sistemi. `apps/worker/lib/challengeDetector.ts` (~200 satir). 4 ChallengeType (NONE, CLOUDFLARE_TURNSTILE, CLOUDFLARE_JS, RECAPTCHA) + 5 ResolutionStrategy (NONE, WAIT, CLICK, FLARESOLVERR_COOKIE, UNSOLVABLE). Dil-bagımsız tespit: `window._cf_chl_opt` JS globals + HTTP 403/503 + page size <50KB. Hardcoded title pattern YOK (CF localized titles). HTML regex yerine `page.frames()` kullanir. Eski 10-sinyalli tier sistemi kaldirildi. hCaptcha/Arkose/CUSTOM_HOLD detection yok.

[Cross-Origin Image Handling]
└─ Category: Archive Quality
└─ Purpose: SingleFile fetch() CORS kısıtlamasını bypass eder. İki katmanlı çözüm: (1) `page.route()` image proxy — Playwright network seviyesinde image request'leri yakalayıp Node.js HTTP ile proxy'ler (CORS yok). (2) Cross-origin image inliner — server-side fetch + base64 data URI injection DOM'a SingleFile öncesi. Browser `<img>` tag'leri CORS'a tabi değil (görseller browser'da görünür), ama JS `fetch()` tabi — bu yüzden SingleFile embed edemiyor.

[Challenge Click Resolver]
└─ Category: Anti-Bot Resolution
└─ Purpose: Cloudflare Turnstile + reCAPTCHA v2 checkbox challenge'lari icin generic click resolver (`apps/worker/lib/fallback/challengeClickResolver.ts`). Iframe bounding box alip human-like mouse movement ile checkbox'a tiklar. CloakBrowser source-level stealth ile birlesip moneysavingexpert.com gibi managed Turnstile siteleri ~3 saniyede geciyor. cf_clearance cookie polling ile dogrulama yapar. ENV: `CHALLENGE_DETECT_MOUNT_WAIT_MS` (3000), `CHALLENGE_RESOLVE_POLL_TIMEOUT_MS` (15000).

[ws]
└─ Category: WebSocket Server (web)
└─ Purpose: Live browser screencast WebSocket endpoint (`/api/ws/screencast`). `apps/web/server.ts` custom server port 3000 üzerinde NextAuth cookie ile auth eder, Redis Pub/Sub'tan frame/status dinleyip client'a iletir.

[ioredis]
└─ Category: Redis Client
└─ Purpose: Redis Pub/Sub ve presence tracking. Worker `screencastRelay.ts` publisher; web `server.ts` subscriber + command client. `worker:status:<uid>` key persistent status, `screencast:viewers:<uid>` sorted set presence tutar.

[redis]
└─ Category: Infrastructure (Docker service)
└─ Purpose: Redis 7 Alpine. Screencast Pub/Sub + worker status persistence için. Port 6379 internal. Healthcheck: `redis-cli ping`.
