== Auth API ==

[GET, POST] /api/v1/auth/* (NextAuth)
└─ File: grabshark/apps/web/pages/api/v1/auth/[...nextauth].ts
└─ Purpose: Authentication handling (Login, Logout, Session, OAuth providers).

[POST] /api/v1/auth/forgot-password
└─ File: grabshark/apps/web/pages/api/v1/auth/forgot-password.ts
└─ Purpose: Password reset request.

[POST] /api/v1/auth/reset-password
└─ File: grabshark/apps/web/pages/api/v1/auth/reset-password.ts
└─ Purpose: Password reset with token. Sets mustChangePassword=false on success — user already chose their own password, force-change loop is satisfied.

[POST] /api/v1/auth/email/send-code
└─ File: grabshark/apps/web/pages/api/v1/auth/email/send-code.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/auth/email/sendCode.ts
└─ Purpose: Generate a 6-digit email verification code for the caller. Body { targetEmail? } — empty defaults to user.email (first-time verify). 60sn Redis cooldown per (user, targetEmail). Code bcrypt-hashed, expires in 10min, prior active codes invalidated. Mail dispatched via DB-driven transporter (getSmtpFrom + getTransporter). 503 if SMTP not configured. Audit category auth.email_verify / code_sent.

[POST] /api/v1/auth/email/verify-code
└─ File: grabshark/apps/web/pages/api/v1/auth/email/verify-code.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/auth/email/verifyCode.ts
└─ Purpose: Validate 6-digit code + commit user.email + emailVerified=now() in one transaction. attempts++, 5'inci yanlışta consumedAt set → kod ölür. Match olunca eski kodlar zaten invalidate edilmiş, hedef adres user.email alanına yazılır. Audit auth.email_verify / verified veya code_locked.

[POST] /api/v1/auth/force-password-change
└─ File: grabshark/apps/web/pages/api/v1/auth/force-password-change.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/auth/forcePasswordChange.ts
└─ Purpose: Consume PasswordChangeChallenge → update user.password + mustChangePassword:false. Anonymous endpoint (challenge token sole credential), AUTH-tier IP rate limit. Token 5min TTL, single-use. Yeni password admin'in eskisinden farklı olmalı. Audit auth/password_changed (security) + account/password_changed (audit).

└─ File: grabshark/apps/web/pages/api/v1/security/sessions/revoke-others.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/sessions/revokeOtherSessions.ts

[POST] /api/v1/security/totp/init
└─ File: grabshark/apps/web/pages/api/v1/security/totp/init.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/totp/initTotp.ts
└─ Purpose: Start TOTP enrollment — generate base32 secret, build otpauth URL, render QR SVG, store AES-GCM-encrypted pending secret in TotpSetupChallenge (15 min TTL). Rejects if user lacks a password or TOTP is already enabled. Rate-limited (AUTH preset).

[POST] /api/v1/security/totp/enable
└─ File: grabshark/apps/web/pages/api/v1/security/totp/enable.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/totp/enableTotp.ts
└─ Purpose: Finish TOTP enrollment. Requires password re-auth + valid 6-digit code. Decrypts pending secret from TotpSetupChallenge, persists to User.totpSecret, generates + hashes 10 recovery codes, returns plaintext codes (one-time display).

[POST] /api/v1/security/totp/disable
└─ File: grabshark/apps/web/pages/api/v1/security/totp/disable.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/totp/disableTotp.ts
└─ Purpose: Turn off TOTP. Requires password + (TOTP code OR recovery code). Wipes User.totpSecret/totpEnabledAt/recoveryCodeSalt + related challenge/code rows atomically.

[POST] /api/v1/security/recovery-codes/regenerate
└─ File: grabshark/apps/web/pages/api/v1/security/recovery-codes/regenerate.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/recoveryCodes/regenerateCodes.ts
└─ Purpose: Rotate recovery codes. Requires password + current TOTP code. Fresh salt + 10 new codes; old set deleted atomically. Returns plaintext codes (one-time display).

[GET] /api/v1/security/recovery-codes/status

[DELETE] /api/v1/admin/users/[id]/2fa

[POST] /api/v1/admin/users/[id]/role
└─ File: grabshark/apps/web/pages/api/v1/admin/users/[id]/role.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/admin/users/updateRole.ts
└─ Purpose: SUPER_ADMIN-only role mutation. Body: { role: "MEMBER" | "ADMIN" | "SUPER_ADMIN" }. canManage() simetrisi: OWNER (NEXT_PUBLIC_ADMIN env id) immune, self-management yok. SECURITY audit log [admin.role_changed] {oldRole, newRole}. Returns { id, role }.

[POST] /api/v1/admin/users/[id]/suspend
└─ File: grabshark/apps/web/pages/api/v1/admin/users/[id]/suspend.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/admin/users/updateSuspension.ts
└─ Purpose: ADMIN+ user suspension toggle.
