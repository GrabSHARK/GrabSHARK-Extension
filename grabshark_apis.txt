== Security API (2FA / Active Sessions / Recovery Codes) ==

[GET] /api/v1/security/sessions
└─ File: grabshark/apps/web/pages/api/v1/security/sessions/index.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/sessions/listSessions.ts
└─ Purpose: Unified list of browser (UserSession) + mobile (AccessToken.isSession=true) sessions for the authenticated user. Marks the current session via token.sid.

[DELETE] /api/v1/security/sessions/[id]?kind=browser|mobile
└─ File: grabshark/apps/web/pages/api/v1/security/sessions/[id].ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/sessions/revokeSession.ts
└─ Purpose: Revoke a single session. Browser → prisma.userSession.delete; Mobile → accessToken.update({revoked:true}). Current session revoke rejected (400) — use sign-out.

[POST] /api/v1/security/sessions/revoke-others
└─ File: grabshark/apps/web/pages/api/v1/security/sessions/revoke-others.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/sessions/revokeOtherSessions.ts
└─ Purpose: Revoke all browser + mobile sessions except the current one (token.sid preserved).

[POST] /api/v1/security/totp/init
└─ File: grabshark/apps/web/pages/api/v1/security/totp/init.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/totp/initTotp.ts
└─ Purpose: Start TOTP enrollment — generate base32 secret, build otpauth URL, render QR SVG, store AES-GCM-encrypted pending secret in TotpSetupChallenge (15 min TTL). Rejects if user lacks a password or TOTP is already enabled. Rate-limited (AUTH preset).

[POST] /api/v1/security/totp/enable
└─ File: grabshark/apps/web/pages/api/v1/security/totp/enable.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/totp/enableTotp.ts
└─ Purpose: Finish TOTP enrollment. Requires password re-auth + valid 6-digit code. Decrypts pending secret from TotpSetupChallenge, persists to User.totpSecret, generates + hashes 10 recovery codes, returns plaintext codes (one-time display).

[POST] /api/v1/security/totp/disable
└─ File: grabshark/apps/web/pages/api/v1/security/totp/disable.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/totp/disableTotp.ts
└─ Purpose: Turn off TOTP. Requires password + (TOTP code OR recovery code). Wipes User.totpSecret/totpEnabledAt/recoveryCodeSalt + related challenge/code rows atomically.

[POST] /api/v1/security/recovery-codes/regenerate
└─ File: grabshark/apps/web/pages/api/v1/security/recovery-codes/regenerate.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/recoveryCodes/regenerateCodes.ts
└─ Purpose: Rotate recovery codes. Requires password + current TOTP code. Fresh salt + 10 new codes; old set deleted atomically. Returns plaintext codes (one-time display).

[GET] /api/v1/security/recovery-codes/status
└─ File: grabshark/apps/web/pages/api/v1/security/recovery-codes/status.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/security/recoveryCodes/getCodesStatus.ts
└─ Purpose: Returns { totpEnabled, total, remaining } for UI display of recovery code inventory.

[DELETE] /api/v1/admin/users/[id]/2fa
└─ File: grabshark/apps/web/pages/api/v1/admin/users/[id]/2fa.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/admin/reset2fa.ts
└─ Purpose: Admin-only emergency 2FA reset — wipes target user's TOTP secret, recovery codes, pending setup & two-factor challenges in one transaction. For users who lost both authenticator and recovery codes. Requires caller to match ADMIN_ID env var.

[GET] /api/v1/admin/logs
└─ File: grabshark/apps/web/pages/api/v1/admin/logs/index.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/admin/logs/listLogs.ts
└─ Purpose: Admin-only multi-type log query. Query params: type (AUDIT|SECURITY|SYSTEM|HTTP|WORKER|INTEGRATION|ALL), category, action, actorUserId, targetUserId, level (DEBUG|INFO|WARN|ERROR), from, to (ISO datetime), cursor (BigInt id desc pagination), take (1-100000, default 50). Returns { items: LogRow[], nextCursor: string|null, hasMore: boolean }. Cursor-based — id < cursor desc. BigInt ids serialized as strings.

[DELETE] /api/v1/admin/logs/purge
└─ File: grabshark/apps/web/pages/api/v1/admin/logs/purge.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/admin/logs/purgeLogs.ts
└─ Purpose: Admin-only retention purge — deletes Log rows of a given type older than N days. Body: { type: LogType, olderThanDays: number }. Audits itself via SECURITY log (admin.logs_purged) so the act of wiping audit history is itself forensic. Returns { deleted: number }.

== Telegram Integration API ==

[GET] /api/v1/telegram/bot
└─ File: grabshark/apps/web/pages/api/v1/telegram/bot.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/telegram/getBotStatus.ts
└─ Purpose: Central status probe for the Integrations UI. Returns { enabled, botConfigured, bot: {username, userId, transport, webhookUrl, pendingUpdates, lastErrorAt, lastErrorMsg, degraded}, pairing: {paired, telegramUsername, firstName, linkedAt, repairNeeded}, isAdmin }. Drives sidebar nav visibility (enabled && (isAdmin || botConfigured)) and all card render branches. Master kill switch (TELEGRAM_ENABLED=false) collapses everything to enabled:false.

[POST] /api/v1/telegram/pair
└─ File: grabshark/apps/web/pages/api/v1/telegram/pair.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/telegram/generatePairCode.ts
└─ Purpose: Generate a one-time pairing nonce (12-byte base64url) for linking a Telegram account. Persists SHA-256(nonce) with 10-min TTL; returns { nonce, deepLink: "https://t.me/<bot>?start=pair_<nonce>", botUsername, expiresAt }. Invalidates any prior unused codes for this user. Rate-limited (AUTH preset). 503 when TELEGRAM_ENABLED=false.

[GET] /api/v1/telegram/pair/status
└─ File: grabshark/apps/web/pages/api/v1/telegram/pair/status.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/telegram/getPairStatus.ts
└─ Purpose: Polled by the pair modal (~5s interval) to detect when the user completed /start pair_<nonce> in Telegram. Returns { paired: false } or { paired: true, telegramUserId, chatId, username, firstName, linkedAt, botUsername, botActive }.

[DELETE] /api/v1/telegram/account
└─ File: grabshark/apps/web/pages/api/v1/telegram/account.ts
└─ Controller: grabshark/apps/web/lib/api/controllers/telegram/unlinkAccount.ts
└─ Purpose: Delete the user's TelegramAccount row + any pending unused pair codes atomically. User can re-pair afterwards by generating a new code.

[POST] /wh/telegram
└─ File: grabshark/apps/web/server.ts (custom server interceptor before Next.js)
└─ Handler: grabshark/apps/web/lib/webhooks/telegramWebhookHandler.ts
└─ Purpose: Telegram webhook ingress. NOT a Next.js API route — mounted on the custom server's /wh/ namespace so we bypass Next's default bodyParser for raw-body access. Validates X-Telegram-Bot-Api-Secret-Token (timing-safe compare), persists (botId, update_id) for idempotency (P2002 = 200 OK duplicate), pushes envelope to Redis list telegram:updates:queue for the worker to dispatch, returns 200/500. 404 when TELEGRAM_ENABLED=false or no active bot. Max body 2MB.
