GrabSHARK Browser Extension Internationalization (i18n Reference)

== Framework & Runtime ==

[i18next]
└─ Category: Translation Engine
└─ Version: ^25.7.3
└─ Purpose: Tarayıcı uzantısının çeviri motoru. Lazy-load locale bundle'larını yönetir, fallback ve interpolation çözer.

[react-i18next]
└─ Category: React Bindings
└─ Version: ^16.5.1
└─ Purpose: i18next'i React component'lerine `useTranslation()` hook'u ile bağlar.

[i18n Initialization]
└─ File: grabshark-extension/src/@/lib/i18n.ts
└─ Purpose: i18next başlatma, browser-language detection, `chrome.storage.local` üzerinden seçili locale persist + change listener.

[Translation Hook]
└─ Function: useTranslation()
└─ Purpose: Component içinde `const { t } = useTranslation()` ile namespaced key lookup (`t('saveLink.title')`).

== Locale Storage ==

[Storage Backend]
└─ API: chrome.storage.local
└─ Key: grabshark_locale
└─ Purpose: Kullanıcının seçtiği dil tercihi. Tarayıcı yeniden açılsa bile korunur.

[Detection Order]
└─ 1: chrome.storage.local.grabshark_locale
└─ 2: navigator.language → normalizeLocale() (zh → zh-CN, vb.)
└─ 3: en (final fallback)
└─ Purpose: Kullanıcı seçtiyse onun dilini, seçmediyse tarayıcı dilini, hiçbiri tutmazsa İngilizceyi yükler.

[Lazy Load Strategy]
└─ Mechanism: Dynamic `import('./locales/{lang}.json')`
└─ Bundling: Locale dosyaları upfront bundle'lanmaz, çalışma zamanında getirilir
└─ Purpose: Bundle boyutunu küçük tutar (sadece seçili dil yüklenir).

== Maintainer Notes ==

[New Key Lifecycle]
└─ Step 1: en.json'a uygun namespace altına yeni key ekle (`{ "saveLink": { "newKey": "..." } }`)
└─ Step 2: 14 locale'in aynı namespace'ine geçici fallback EN değerle ekle
└─ Step 3: `crowdin upload sources` ile push
└─ Step 4: Community çevirisi sonrası `crowdin download translations`
└─ Step 5: Yapısal sanity check (flatten + EN sırası vs.)

[Code Usage Pattern]
└─ Import: `import { useTranslation } from "react-i18next"`
└─ Hook: `const { t } = useTranslation()`
└─ Lookup: `t('saveLink.title')` (dot path)
└─ Interpolation: `t('saveLink.savedSuccess', { count: 3 })`

[i18n vs Web App]
└─ Web App File: locales/{lang}/common.json (folder per lang) — flat 1083 key
└─ Extension File: locales/{lang}.json (file per lang) — nested 155 key
└─ Crowdin: 2 ayrı proje (TM paylaşılmaz, ama tek hesap & token altında)
└─ Reasoning: Lifecycle farklı (web private/release, extension store-distributed)

[i18n Sync Rule]
└─ Rule: Bu dosya kod tarafında yeni namespace/key girdiğinde anında güncellenmeli
